# 디지털 공간에서 정보의 확산 속도 체험하기

중학교 정보 **5단원 디지털 문화** 수업용 웹앱입니다.
2022 개정 교육과정 성취기준 **[9정05-02] · [9정05-03]** 과 연결되며,
교과서 「해 보기 1 — 디지털 공간에서 정보의 확산 속도 체험하기」 활동을 그대로 옮겼습니다.

> ⚠️ 앱에 나오는 학교·주소·전화번호 등 개인 정보는 **모두 수업용으로 지어낸 가상의 정보**입니다.

## 바로 써 보기

- **수업 화면** — `index.html`
- **확산 그림 시안 비교(참고용)** — `alt-views.html`

`index.html` 을 **더블클릭해서 바로 열 수 있습니다.**
외부 라이브러리·CDN·이미지 파일을 하나도 쓰지 않아 인터넷 없이도 동작합니다.

## 활동 순서 (4단계)

| 단계 | 학생이 하는 일 |
|:---|:---|
| **1. 사진 올리기** | 인스타 모양 게시물에서 **개인 정보가 담긴 해시태그를 직접 골라 보고**, 게시하면 채점 결과와 「사진 한 장에 이만큼이 담겨 있었어요」 목록이 열린다 |
| **2. 문제 풀기 (예상)** | 교과서 관계망 그림을 보고 문항 (1)(2)(3) 의 답을 **먼저 예상해서** 쓴다 (정답 700 / 3,100 / 3,800명) |
| **3. 퍼지는 모습 (확인)** | **도는 지구본** 위에서 한국(서울) → 육지를 따라 전 세계로 4차 782명까지 퍼지는 모습을 보며 예상을 확인한다 |
| **4. 더 알아보기** | 팔로워 수를 바꿔 보고, **「글을 지워도 확산은 멈추지 않는다」** 를 직접 겪어 본다 |

각 단계는 앞 단계를 마쳐야 열립니다.

## 특징

- **교과서 예시답안과 정확히 일치** — 1차 7명(700명) · 2차 31명(3,100명) · 10분 안에 3,800명.
  화면이 4차 확산까지 보여 주더라도 **문제 채점은 언제나 1·2차 기준**으로 고정됩니다.
- **도는 지구본** — 사람은 육지에만 앉고, 지구는 확산이 향하는 쪽으로 돕니다.
  확산이 끝난 뒤에는 **끌어서 직접 돌려** 볼 수 있습니다(가로=회전, 세로=기울기).
- **글 삭제 체험** — 글을 지워도 본 사람 수는 줄지 않고 계속 늘어납니다.
- 학생 개인정보를 **수집하거나 저장하지 않습니다.**

## 개발

```bash
npm install     # 처음 한 번
npm start       # 개발 서버 → http://localhost:8083
npm test        # 단위 시험 59개
npm run build   # dist/ 생성
```

| 파일 | 설명 |
|:---|:---|
| `index.html` | 수업 화면 전체 |
| `spread-core.js` | 계산 부분 (관계망·인원·채점). DOM 의존 없음 → node 로 시험 가능 |
| `main.js` | 지구본 그리기, 애니메이션, 단계별 진행 |
| `style.css` | 스타일 (교실 TV 대응) |
| `alt-views.html` | 확산 그림 시안 비교 페이지 |
| `tests/run-tests.js` | 단위 시험 |
| `CLAUDE.md` | 개발 기록 — **고치기 전에 먼저 읽어 주세요** |
